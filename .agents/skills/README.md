# Matt Pocock skills for Codex

This directory contains 22 skills adapted from
[`mattpocock/skills`](https://github.com/mattpocock/skills), installed for
Codex through the Agent Skills standard. The upstream baseline is
`ed37663cc5fbef691ddfecd080dff42f7e7e350d`; the local copies intentionally use
lighter, judgment-based entrypoints and progressive disclosure.

`skills-lock.json` records that upstream baseline. Review upstream changes
before merging them; a blind skills update may overwrite the local adaptations.

The upstream Claude plugin is not required. Deprecated, in-progress, personal,
and miscellaneous skills are intentionally excluded.

See `MATTP0COCK-LICENSE` for the upstream MIT license.
