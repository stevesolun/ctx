# Wayfinder workflows

## Chart a map

1. Confirm the effort is genuinely large and unclear.
2. Define the destination and boundaries.
3. Gather existing decisions and evidence.
4. Add only questions precise enough to investigate.
5. Record remaining uncertainty as fog tied to known dependencies.
6. Identify the initial frontier.

## Advance a map

1. Select a frontier question based on value, dependency impact, and available
   ownership.
2. Choose the least expensive evidence that can resolve it: conversation,
   repository inspection, research, prototype, or a small task.
3. Record the answer and evidence in one place.
4. Update dependencies, graduate newly precise fog into questions, and close
   questions that no longer matter.

## Coordinate parallel work

Run questions concurrently when they are independent and have disjoint
ownership. Claim work using the tracker's native mechanism when available.
Serialize shared decisions and competing writes through one coordinator.

## Hand off

When remaining work is execution rather than uncertainty reduction, summarize
the destination, decisions, unresolved risks, and source links for the next
planning or implementation workflow.
