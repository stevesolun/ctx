# Teaching principles

## Ground the work

- Tie lessons to a practical mission rather than an abstract content list.
- Estimate the learner's current understanding from conversation and prior
  work; revise that estimate as evidence arrives.
- Keep each lesson within a productive challenge range: achievable with effort,
  but not automatic.

## Build durable understanding

- Distinguish immediate fluency from long-term retention.
- Use retrieval practice, spacing, interleaving, examples, and feedback when
  they fit the material and learner.
- Teach knowledge in service of a skill or decision instead of maximizing
  coverage.
- Encourage real-world practice when it adds evidence that exercises cannot.

## Preserve state selectively

For continuing work, choose only useful artifacts:

- `MISSION.md` for the learner's purpose.
- `RESOURCES.md` for vetted sources.
- `learning-records/` for durable insights and changes in understanding.
- `reference/` for reusable summaries.
- `lessons/` for lesson artifacts when a file is better than conversation.

Avoid creating empty scaffolding. Existing format files in the skill directory
are optional templates, not mandatory outputs.
